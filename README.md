# 📖 Daily Aphorisms (Günlük Aforizmalar)

[![Flutter](https://img.shields.io/badge/Flutter-3.x-blue.svg)](https://flutter.dev/)
[![Platform](https://img.shields.io/badge/Platforms-Android%20%7C%20iOS-orange.svg)]()
[![License](https://img.shields.io/badge/License-MIT-green.svg)]()

A sleek, minimalist daily aphorism and philosophy quote application built with Flutter. Provides daily philosophical wisdom, aesthetic home-screen widgets, favorites management, and offline local quote caching.

---

## 🚀 Features

- **Daily Wisdom:** Curated database of quotes from stoicism, existentialism, Eastern philosophy, and classical literature.
- **Home Screen Widget:** Native home-screen widget support for daily glanceable inspiration without opening the app.
- **Aesthetic Typography:** Clean, distraction-free reader interface with dynamic typography and smooth animations.
- **Favorites & Sharing:** Save favorite aphorisms to local storage and share with one-click image export.

---

## 🛠️ Tech Stack

- **Framework:** Flutter 3.x / Dart 3.x
- **Architecture:** Clean Provider / Service pattern
- **Storage:** Local persistence (SharedPreferences)
- **Native Interop:** Android Home Screen AppWidget integration

---

## 💻 Getting Started

```bash
# Clone the repository
git clone https://github.com/EmreAlgurr/DailyAphorisms.git
cd DailyAphorisms

# Fetch dependencies
flutter pub get

# Run on connected device or emulator
flutter run
```
